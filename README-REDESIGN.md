## Running it

```bash
cd "public_html 2/v2"
php artisan serve --port=8001
# http://127.0.0.1:8001
```

With hot-reload assets (after `npm install`):

```bash
npm install
npm run dev
php artisan serve --port=8001
```

## What was cleaned up

Removed from the copied app (all unused / duplicate / unsafe):

- **Unused images** — simha, mayura, mriga, circle (×2), villaview,
  FutureInfrastructureAroundRamnagar (×2), villa_koruvilla.webp,
  tigerzindahai.png, Logo.png, popup.jpg, the typo `popup.jpgwed`, and the
  loose `.jpeg` fallbacks not referenced anywhere.
- **Duplicated CSS/JS** — `public/css/blog.css` and `public/js/blog.js` were
  byte-identical copies of `resources/css|js/blog.*`. `resources/` is the
  single source of truth (Vite builds them into `public/build/`).
- **Unused 28 MB video** — `public/video/koruville.mp4` (zero references) and
  the empty `public/assets/video/` dir.
- **Stray dev database** — `database/database.sqlite` (production uses MySQL).
- **Stale build output** — `public/build/` (regenerated by `npm run build`).
- **Secrets / editor config** — `.vscode/sftp.json` contained **live FTP
  credentials**; removed.
- **Legacy flattened-layout files** — root `index.php`, root `.htaccess`
  (both replaced by the standard `public/` equivalents).
- **Duplicate docs** — `CODEBASE-FINDINGS.md` copy (original stays at project
  root).
- Empty 0-byte `public/favicon.ico` (the real icon is in `assets/`).

Relocated to their correct locations:

- Brand assets: root `assets/` → `public/assets/`
- `robots.txt`, `llms.txt` → `public/`

## Database

`.env` points at the **same production MySQL** (`koruvilla_blog`) so the
redesign reads real content out of the box.

```
DB_CONNECTION=mysql
DB_HOST=127.0.0.1     ← set to your local/host MySQL
DB_DATABASE=koruvilla_blog
```

No MySQL is running on this machine yet. Start one, then set `DB_HOST`.
Sessions/cache use an isolated cookie name + cache prefix so they never
collide with the live site.
